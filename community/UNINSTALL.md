# Снятие пакета `[DBG] Kristiano Fixes ALL IN ONE`

Игроку: выборочно отключить один фикс из AIO **нельзя** — только весь слот в MO2.
Разделы **Удаление** в отдельных `addon/*/CHANGELOG.md` — справка для разработки, не чек-лист игрока.

Этот документ — **одна** процедура на весь пакет.

Отдельные zip (не входят в AIO, снимаются сами):  
`[FIX] Campfires Anthology Compat`, `[HUD] Context Menu_Overhaul_Anthology`,  
`[SND] Anthology ST2 Mutant Footstep Sound`, QuickQK Task Status Tool.  
У Campfires своё правило: сначала убрать поставленные костры, потом слот.

---

## Необратимое (прочитать до снятия)

### `fix_gigant_space_restriction` — единственный риск такого класса в пакете

Пока пакет стоял, мод мог писать в alife `set_switch_online(false)` (карантин) и при необходимости делать `alife_release` небезопасных гигантов.

- **Release** — объект исчез навсегда (так задумано против CTD). Откатить нельзя.
- **Сессионный карантин** (`off_level` / уровень не готов / смена локации) — с **1.1.2** снимается на `on_game_end` (`set_switch_online(true)`), если последняя сессия с включённым пакетом дошла до выгрузки. Персист `false` был побочным эффектом сериализации API, не замыслом мода.
- **Не закрывается кодом:** сейв уже лежит на диске с `false`, и вы выключаете AIO в MO2 **без** запуска игры — `on_game_end` не отработает.

Среди модов пакета больше ни у кого нет `set_switch_online`.


---

## Реально ли это игроку

Чек-лист из десятка квестов и логов **никто не выполнит**. Хуже отсутствия инструкции.

Сжатая процедура ниже — **три шага**, которые покрывают почти все мягкие случаи.  
Для гигантов важен именно **выход в меню** в шаге 1 (не чек-лист из 15 пунктов).

Если пакет снимают «просто выключить в MO2» без шагов 1–2: сейв обычно живёт, но возможны сироты KX-1, незавершённый SGM-труп (FATAL) и offline-гиганты (если не было выгрузки с 1.1.2+).

## Что сделать до снятия (порядок)

### 1. Один load с включённым AIO → подождать → сохранить

Загрузите сейв с пакетом **включённым**, постойте / перейдите на другой уровень (~30–60 с или до обычного автосейва), **выйдите в меню** (чтобы отработал `on_game_end`), затем сохранитесь вручную при необходимости.

Этим одним проходом закрываются:

- одноразовые починки, которым нужен работающий мод (миграция тайников, переписи Aver/Купол, ремонт меток и т.д. — таблица ниже);
- **снятие сессионного карантина гигантов** (`fix_gigant_space_restriction` 1.1.2+): в логе строка `exit quarantine freed=…`. Без этого запуска сейв с уже записанным `set_switch_online(false)` и выключение AIO в MO2 оставляют гигантов offline.

| Что успевает сработать | Моды |
| --- | --- |
| Миграция типов квестовых тайников | `fix_quest_stash` |
| Перенос лута с закрытых ящиков | `fix_locked_stash_boxes` |
| Перепись dest переходов Aver | `fix_aver_darkvalley` |
| Очистка `fixed_bones` Купола | `fix_kupol_wrong_bone` |
| Ремонт метки Левши / story map | `fix_quest_story_id` |
| Ремонт `active_section` тайника Ильи | `fix_vows_ambush_stash` |
| Очистка битых caches / fetch-ключей | `fix_stash_id_desync`, `fix_stale_fetch_marker` |
| Снятие сессионного карантина гигантов | `fix_gigant_space_restriction` (на выходе в меню) |


### 2. Условные проверки (только если относится к вашему сейву)

Сделайте **до** выключения слота, после шага 1:

| Если … | Сделайте |
| --- | --- |
| Надели / носите предметы **KX-1** (костюм, каркас, флешка, чертёж) или ещё открыт сюжет флешки | Снимите/ выбросьте эти предметы, закройте сюжет, сохранитесь. Иначе после снятия — предметы без секций и сироты `save_state`. (`kristiano_kx1_exo`) |
| Активно SGM-задание на **труп** (Громобой / Касилов / Science Report и аналоги) | Сдайте или провалите квест, сохранитесь. Иначе без пакета снова FATAL `replace_quest_corpse`. (`fix_replace_quest_corpse`) |
| Сейчас идёт анимация **спичек** у костра | Дождитесь конца / не снимайте mid-action. (`fix_matches_campfire_softlock`) |
| Висит shared DRX stash-квест, который «vanish-fail» | Лучше дождаться fail с пакетом или завершить задание. (`fix_quest_item_shared_fail`) |

Не ваш случай — пункт пропускаете.

### 3. Выключить слот AIO в MO2

Полностью отключите `[DBG] Kristiano Fixes ALL IN ONE`. Новая игра не нужна.  
Перезапустите игру / загрузите сейв ещё раз (UI-хуки и обёртки живут до reload сессии).

## Что останется в сейве навсегда (это хорошо)

После шага 1 эти правки **не откатятся** и **не требуют** держать пакет:

- пустой `fixed_bones` у объекта Купола;
- исправленные координаты level_changer Aver;
- мигрированные `stash_type` DRX → Anthology;
- починенные `active_section` / метки / очищенные битые caches и fetch-ключи;
- `alife_release` уже уничтоженных (Burn Shit ПКМ, небезопасные гиганты) — штатный минус мира, не порча формата сейва.

Это не «мусор после мода», а уже записанный результат починки.

---

## Что вернётся из багов (ожидаемо)

Без AIO снова возможны исходные проблемы, которые пакет закрывал: CTD BusyHands / nil-guard'ы, кривые квесты и телепорты без одноразовой починки, петля DRX meet, десинк тайников, арена, радио, WTF-счётчики и т.д.  
Полный список — смысл отдельных CHANGELOG; игроку достаточно знать: **снятие ≠ «ваниль стала стабильнее»**, это отказ от гардов.

---

## Итог для поста беты

1. **Гиганты:** с 1.1.2 сессионный карантин снимается при выходе в меню; единственная дыра — выключить AIO без запуска, когда сейв уже с `false`. `alife_release` по-прежнему необратим.  
2. **Реальная процедура игрока:** load → (по ситуации KX-1 / труп-квест) → **меню** → save → выключить AIO.  
3. Длинный чек-лист по 82 модам **не публиковать**.
