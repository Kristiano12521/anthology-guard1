Что проверить в игре. Без аргументов.

Список: `python3 tools/lint_addon.py --unverified`. Для каждого мода — `addon/<mod_id>/CHANGELOG.md` (последняя запись) и `meta.ini`. Порядок проверки: [`docs/mo2.md`](../../docs/mo2.md#проверка-в-игре).

Сгруппируй: **поведение** (механика, callback, state, UI) — важнее; **текст/логирование** — второй приоритет. Для каждого — конкретный чек-лист в игре из CHANGELOG, не общие слова.

Формат: приоритет → `mod_id` → что смотреть → как отметить (`verified_date`, `verified_build`, `verified_note` в `meta.ini`; ставит человек). Код и `verified_*` не трогай.
