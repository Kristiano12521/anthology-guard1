Сверка форка с оригиналом. Аргумент после `/fork` — `mod_id`. Нет id — спроси и остановись.

Только если в `meta.ini` стоит `vendor_fork=1`; иначе скажи и остановись. Оригинал — `vendor_source` в `reference/addons/`. Сверка `FORK-001`: [`docs/mo2.md`](../../docs/mo2.md#проверка-в-игре).

Запусти `python3 tools/lint_addon.py <mod_id>` и собери предупреждения `FORK-001`. Пропавшие файлы — с учётом переименований по префиксам `zzz`/`aaa` (линтер сверяет через `fork_match_key`). Файлы только в форке, не в оригинале — наши добавления.

Если `vendor_source` пуст или папки нет в `reference/addons/` — назови это. Ничего не исправляй.
