# reference/ — эталонные исходники сборки

**Только чтение.** Ни агент, ни человек не создают и не меняют здесь файлы. Всё, что нужно изменить, делается наложением из `addon/`.

Содержимое в git не хранится (объём и лицензия) — папку наполняешь локально.

Ожидаемая раскладка:

```
reference/
├─ anomaly/     распакованная gamedata Anomaly 1.5.3 (scripts, configs, text)
├─ anthology/   gamedata Anthology 2.1
├─ addons/      gamedata ключевых аддонов сборки, по папке на аддон
└─ docs/        README Modded Exes и прочие текстовые справочники
```

Текстуры, модели и звуки не нужны — они не участвуют в анализе кода.

После наполнения или обновления сборки:

```bash
python3 tools/refindex.py build
```

Подробности: [`../docs/setup.md`](../docs/setup.md).
