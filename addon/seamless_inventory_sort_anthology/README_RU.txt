ИЗМЕНЕНИЯ 1.5.2
----------------
- Быстрая очистка подсветки подтверждена A/B-тестом с 901 предметом игрока.

- Диагностику можно временно включить в MCM для последующих исследований.
- Все type guards, Antifreeze, Tooltip Control и NPC Loot Claim fixes сохранены.

ИСПРАВЛЕНИЯ 1.5.1
----------------
- Исправлен вылет при открытии торговли:
  count_entries больше не вызывает pairs() для boolean id_list.
- ParseInventory считает количество предметов по возвращённой таблице.
- Predicate и units-счётчики профилировщика выполняются через pcall.
- Ошибка диагностического счётчика больше не прерывает штатный торговый код.
- Быстрая очистка подсветки и все изменения 1.5.0 сохранены.

ИЗМЕНЕНИЯ 1.5.0
----------------
- Добавлен целевой профилировщик торгового интерфейса.
- Отчёты создаются только при открытой торговле и не используют постоянный
  actor_on_update.
- Измеряются: полный UI Update, UpdateInfo, UpdateItems, обновление торговых
  списков, Reinit контейнеров, UICellContainer.Update, UICellItem.Update,
  проверки торгового статуса, стоимость, подсказки, Add/RemoveItem и scroll.
- В лог выводятся BEGIN, периодические REPORT/TIMES/COUNTS, SLOW и финальный END.
- Добавлена первая безопасная оптимизация: быстрая очистка подсветки.
  Штатный UI при отсутствии наведённого предмета каждый кадр проходил все
  ячейки всех контейнеров. Теперь обрабатываются только реально подсвеченные
  ячейки. Функция включается и отключается отдельно в MCM.
- Никакого кэширования цен или разрешений торговли пока нет: сначала лог должен
  подтвердить следующий наиболее дорогой этап.
- Все исправления 1.4.3 сохранены.

РЕКОМЕНДУЕМЫЙ ТЕСТ 1.5.0
-----------------------
1. Вернуть в рюкзак примерно 650–750 предметов.
2. У того же торговца открыть торговлю на 30–40 секунд.
3. Первые 10 секунд не двигать курсор.
4. Затем провести курсором по обеим торговым сеткам и прокрутить их.
5. Продать 15–20 предметов и купить 5–10.
6. Закрыть и открыть торговлю ещё два раза.
7. Корректно выйти из игры и прислать полный xray-лог.

СОСТАВ
------
Единый архив объединяет и адаптирует:
- Seamless Inventory Sort;
- Inventory Antifreeze;

- Razfarg Slow Scroll Fix v3.

NPC Loot Claim исключён из архива начиная с v1.5.3 (удалён по решению

Если ранее использовалась версия с NPC Loot Claim и её геймплей нужен —
ставьте No-sorting NPC Loot Claim Continued отдельным, независимым моддом.

Отдельные версии перечисленных аддонов одновременно устанавливать не нужно.

ОПТИМИЗАЦИЯ ИНВЕНТАРЯ И ТОРГОВЛИ
---------------------------------
- Большие списки сортируются и создают иконки по кадрам с временным бюджетом.
- Бесшовная сортировка ждёт завершения Antifreeze.
- Серии покупок и переносов объединяются в одну итоговую обработку.
- В режиме «Только поступления» сторона удаления в торговле не уплотняется.
- Крупные торговые сумки защищены настраиваемым лимитом.
- Малые и неподдерживаемые UICellContainer используют штатный код.
- Постоянного actor_on_update нет.

SLOW SCROLL FIX
---------------
Исправление медленной прокрутки встроено непосредственно в Reset контейнера,
уже перехваченный Antifreeze. Отдельный глобальный wrapper не создаётся.

При сбросе безопасно очищаются:
- scroll_tg;
- drag_area.down / drag_area.up;
- owner.item_in_hold;
- scroll_pause.

Добавлены проверки nil для компактных и сторонних контейнеров.

TOOLTIP CONTROL
---------------
- Сохранены оригинальные режимы показа и MCM.
- Хуки и callbacks устанавливаются только один раз.
- Wrapper-функции возвращают результат исходных методов.
- Повторный GUI_on_show одного окна не считается наложенным интерфейсом.
- При отключении управления задержкой восстанавливаются реальные исходные
  значения каждого tooltip, а не условное значение по умолчанию.
- Опциональные мастерские/ремонт патчатся без сообщений об ошибке, если их нет.
