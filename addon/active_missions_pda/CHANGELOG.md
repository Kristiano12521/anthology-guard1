# Changelog — Active Missions PDA Tab (Anthology)

## 1.3.1 — 2026-09-23

- `save_tab_space` (Задания внутри вкладки Объявления) включено по умолчанию — отдельная кнопка Заданий не занимает место на полоске вкладок PDA.
- Нужна вкладка Объявления (Taskboard). Перезапуск игры после смены опции.

## 1.3.0 — 2026-09-23

- Убран override `zzzz_pda_tabs_pager.script` — геометрией полосы занимается отдельный аддон `pda_tabs_layout`.
- Остаются: вкладка Missions, DXML-inject, hook секции, MCM группировки/хоткея.

## 1.2.6 — 2026-09-23

- Пейджер: возврат к схеме Anthology (одинаковая ширина вкладок) + ровный зазор 4px между каждой кнопкой и стрелками. Убраны nest по скосу и ширина «по тексту» — из‑за них края наезжали неравномерно.

## 1.2.5 — 2026-09-23

- Пейджер в формате эталонной полосы КПК: ширина вкладки от длины подписи, стыковка скоса `width − 11` (параллельные края), до 7 вкладок + `>>` на странице; при переполнении — пропорциональное сжатие только текстовых вкладок.

## 1.2.4 — 2026-09-23

- Пейджер: отказ от «стыковки» скоса (`x += width − slant`) — она как раз клала кнопки друг на друга.
- Вместо этого явный зазор 6px между боксами (`x += width + gap`), 5 вкладок на страницу, ширина ~80 без растягивания пустой полосы.

## 1.2.3 — 2026-09-23

- Пейджер вкладок переработан под геометрию `ui_inGame2_pda_button` (скос ~10px):
  - шаг `width − nest` (nest = slant − 2px seam) — ровный стык без наложения и без дыр;
  - ширина вкладок фиксирована (~78), пустая страница не растягивает кнопки;
  - одинаковый шаг для `<<`, вкладок и `>>` на всех трёх страницах.

## 1.2.2 — 2026-09-23

- Пейджер: на странице с `<<`/`>>` было 7 скошенных вкладок встык — края наезжали. Теперь 6 на страницу, зазор 12px между каждой кнопкой (включая стрелки), ширина без переполнения полосы.

## 1.2.1 — 2026-09-23

- Пейджер вкладок КПК: равномерный зазор 8px между скошенными кнопками и стрелками (больше не наезжают друг на друга).

## 1.2.0 — 2026-09-22

- Порт Active Missions PDA Tab 1.2 (ModDB) под Anomaly 1.5.3 / Anthology 2.1.
- Русские строки: вычитан перевод UI/MCM (термины Anthology/Taskboard «Объявления», короткие типы заданий).
- Override `zzzz_pda_tabs_pager.script`: `eptActiveMissions` сразу после Area Map в `real_order`, чтобы вкладка попадала в пейджер Anthology.
- DXML-инжектор не rescale'ит полосу вкладок, если загружен `zzzz_pda_tabs_pager` (геометрией владеет пейджер).
- В классификатор типов добавлены story-functor'ы Anthology (`redemption_*`, `hidden_threat_*`, `agr_u_bandit_boss_*`).
