Active Missions PDA Tab — Anthology 2.1
========================================

Порт аддона Active Missions PDA Tab 1.2 под сборку Anomaly 1.5.3 / Anthology 2.1.

Что делает
----------
Отдельная вкладка PDA «Missions»: активные задания с группировкой по типу /
локации / фракции, карточки с брифингом, трекинг задания.

Установка
---------
1. Поставить zip отдельным модом в MO2.
2. Включить ПОСЛЕ ядра Anthology (нужен override пейджера вкладок).
3. Не класть внутрь [DBG] Kristiano Fixes ALL IN ONE — это отдельный аддон.

Совместимость
-------------
- iTheon PDA Taskboard: опция MCM «Save PDA tab space» (по умолчанию выкл.).
- Interactive PDA: поддерживается.
- Сейвы: своих данных в сейв не пишет.
