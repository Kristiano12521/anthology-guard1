# Burn Shit Inventory Destroy

Anomaly 1.5.3 / Anthology 2.1. Безвозвратное уничтожение предметов из обычного инвентаря через ПКМ.

## Действия

- **Уничтожить** — выбранный предмет в рюкзаке, если его не блокируют экипировка, избранное, квест или `can_trade`.
- **Уничтожить всё** — по умолчанию на **каждом** предмете инвентаря, включая экипированные и защищённые. Удаляет только разрешённые объекты из рюкзака.

Перед удалением всегда подтверждение Да/Нет. Предметы не выбрасываются на землю: `alife_release_id`.

## Установка

1. Выключить старые ZIP `Anthology_Burn_Shit_Inventory_Destroy_Extension` **v1.0.0–v1.0.5** (у 1.0.4 файл `zzzzzz_anthology_burnshit_inventory_destroy.script` иначе перебьёт этот мод).
2. Поставить этот аддон в MO2 **ниже**:
   - `[GAM] Burn Shit`
   - Context Menu Overhaul (если есть)
3. Новая игра не нужна. Если в MCM уже сохранено «Только если доступно несколько предметов» — пункт всё равно появится на защищённых вещах; для показа на каждом предмете выбери **Всегда**.

## Проверка

1. ПКМ по экипированному или избранному: «Уничтожить» нет, «Уничтожить всё» есть.
2. ПКМ по обычному хламу в рюкзаке: есть «Уничтожить».
3. «Уничтожить всё» → Нет: ничего не исчезает.
4. В `xray.log`: `[BurnShitInventoryDestroy] loaded v1.0.6`.
