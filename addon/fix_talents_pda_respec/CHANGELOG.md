# Talents PDA Respec Fix

## [1.0.0] — 2026-08-29

**Изменено**

- `gamedata/scripts/fix_talents_pda_respec.script` — monkey-patch `talents_gui.TalentsMenu`: во вкладке ПДА кнопка респека поднимается на величину обрезания, а при подтверждении сброса правая панель (ветки, полосы, статы, кнопка, тултип) временно скрывается.

**Причина**

Вкладка «Таланты» в ПДА сдвигает фон на `(28, 34)`, чтобы обойти хром КПК. Кнопка респека сидит у нижнего края правой панели и уезжает за клип вкладки — в компактных скинах Milspec PDA / Tactical 1440p Compact до неё нельзя дотянуться.

Окно подтверждения в этом же скинах без непрозрачного фона: текст «Да/Нет» рисуется поверх уровней веток, прогресс-баров и статов.

ZIP `Classes_Talents_PDA_Respec_Fix_v1.0.1` подменял весь `talents_gui.script`. Побочно:

- `ResetLeftTalents` всегда гасит artwork дерева (`background:Show(false)`), в том числе в отдельном окне, не только во вкладке;
- переписан тултип;
- дубль `PDA_GUI = nil`;
- любой другой патч того же файла проигрывает конфликт.

**Как исправлено**

Callback и DLTX не подходят: координаты и Show() — методы экземпляра `TalentsMenu`, XML один на вкладку и на отдельное окно. Monkey-patch:

- после `BuildTalentsMenu` кнопка сдвигается вверх только если её низ плюс смещение `bg` вылезает из `talents_descr_cont`; повторно не двигается;
- `OnClickRespec` / `No` / `Yes` показывают или убирают оверлей только при `is_pda_tab`;
- `Update` гасит тултип, пока висит подтверждение;
- `RefreshForOpen` сбрасывает оверлей при повторном открытии вкладки.

**Не затронуто**

- файл `talents_gui.script` (нет полной замены)
- отдельное окно Classes & Talents
- цена респека, `talents_functions.respec_talents` / `talents_leveling.respec_levels`
- выбор класса, деревья, тултипы в обычном режиме
- artwork левой панели
- `all.spawn`, сейвы, MCM

**Совместимость**

- Anomaly 1.5.3 / Anthology 2.1 / Modded Exes MT
- Сейвы: без миграции, ничего не пишет
- Зависимость: `[GAM] Classes & Talents`. Без него — no-op
- В MO2 ниже Classes & Talents
- ZIP `Classes_Talents_PDA_Respec_Fix` выключить. Если его `talents_gui.script` влили внутрь мода классов — вернуть оригинал

**Проверено**

- lint: `python tools/lint_addon.py fix_talents_pda_respec`
- В игре: не прогонялось. Ожидаемый лог: `[fix_talents_pda_respec] loaded v1.0.0 wrapped=7 missing=0`. Вкладка Таланты в компактном ПДА: кнопка «Респец.» видна и нажимается; подтверждение не перекрыто ветками; «Нет» возвращает правую панель; отдельное окно без изменений
