# Fetch Remote Storage

**Требования:** Anomaly 1.5.3 / Anthology 2.1 / Modded Exes MT; Utjans QoL (fetch count на доске). Soft-deps: Hideout Furniture, The Anomalous Stash.

**Удаление**

- Отключить слот в MO2; новая игра не нужна.
- Сейв не затрагивается.

## [1.1.0] — 2026-09-20

**Изменено**

- Только отображение на «Объявление»: нужная секция в онлайн-ящиках поблизости (свои тайники + верстак HF + аномальный схрон) с красной/жёлтой/зелёной меткой как у инвентаря.
- MCM снят.
- Сдача / статус квеста из удалённых ящиков убраны — без доп. функций.

**Причина**

Utjans считал только `player_created_stashes`, поэтому верстак/`anom` всегда показывали x0.

**Не затронуто**

- Тексты Utjans (`st_fetch_count_*`)
- `set_switch_online`, сейвы

**Совместимость**

- Сейвы: без изменений
- MO2 ниже Utjans QoL

**Проверено**

- lint: `python tools/lint_addon.py fetch_remote_storage`
- в игре: не прогонялось. Ожидание: нужный предмет в верстаке/тайнике рядом — ненулевой счётчик с цветом как у инвентаря
