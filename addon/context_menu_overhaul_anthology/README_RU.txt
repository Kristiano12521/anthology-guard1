  по всей секции на каждую строку.


НОВОЕ В 1.2.1
--------------
В Context Menu Overhaul встроена совместимость с Quick Action Wheel.

В контекстном меню используется одна штатная команда:

«Добавить в колёсико»

Поведение:
- на ручной вкладке QAW предмет добавляется в выбранную вкладку;
- при выбранной динамической вкладке предмет направляется в основную ручную
  вкладку Manual Tab;
- если основная ручная вкладка отключена, используется Second Manual Tab;
- пункт скрывается, когда выбранная ручная вкладка заполнена;
- пункт скрывается для уже добавленного предмета;
- пригодность предмета определяет сам Quick Action Wheel.

Интеграция устанавливается вместе с CMO. Отдельный патч совместимости не нужен.
После завершения инициализации временная проверка регистрации отключается и
не создаёт постоянной нагрузки на кадр.


ПЕРЕОБОРУДОВАНИЕ МАГАЗИНОВ
--------------------------
Поддержка «Переоборудовать» не ограничена вручную заданным списком магазинов.

Универсальный определитель:
- сканирует все загруженные секции магазинов;
- сохраняет штатные retool_group из Mags Redux;
- находит дополнительные связи через привязки калибров оружия;
- сопоставляет физические семейства магазинов по модели, варианту и ёмкости;
- учитывает совместимые магазины из других активных модов;
- строит индекс один раз и затем использует кэш.

Для предоставленной сборки R.A.K Mags Redux проверено:
- 237 секций магазинов;
- 97 штатных маршрутов переоборудования;
- 37 дополнительных маршрутов;
- 134 магазина с реальным вариантом переоборудования.

Пункт «Переоборудовать» не показывается, когда в конфигурации отсутствует
другой реальный магазин-результат. Фиктивные секции не создаются.


ПРАВИЛА ПЕРЕОБОРУДОВАНИЯ
------------------------
- Магазин должен быть полностью пуст.
- В инвентаре должен находиться leatherman_tool.
- Семейства с несколькими калибрами переключаются между существующими вариантами.
- Штатные группы Mags Redux имеют приоритет.
