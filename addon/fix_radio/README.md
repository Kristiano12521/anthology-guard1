# Radio Fix

Anomaly 1.5.3 / Anthology 2.1. Monkey-patches only. Does not replace Hideout Furniture or vanilla scripts.

## MO2

1. Turn **off** `Hideout_Furniture_Placeable_Radio_Fix.zip` (it overwrites `placeable_radio.script` and drops extra stations).
2. Restore original `gamedata/scripts/placeable_radio.script` from **[HF] Hideout Furniture**.
3. Do **not** keep the custom `track_21.ogg` from that zip unless you want that song in Zone FM.
4. Install this addon **below** Hideout Furniture.

## In game

- Options → Sound → Radio → Zone: silences base radios and notebooks, including `play_sound` devices.
- Look at a radio/notebook: use to toggle, shoot to break (any bone).
