# ST2 Mutant Footstep Fix

DLTX overlay for `[SND] S.T.A.L.K.E.R_MUTANTS`. Does not replace the sound pack files.

## Install

1. Place below `[SND] S.T.A.L.K.E.R_MUTANTS` in MO2.
2. Disable `Anthology_ST2_Mutant_Footstep_Sound_Fix_v1.0.0` if it is installed (same filenames as the pack).
3. Restart the game. New game is not required.

Requires the ST2 mutant sound pack. Without it the patched sections do not exist.
