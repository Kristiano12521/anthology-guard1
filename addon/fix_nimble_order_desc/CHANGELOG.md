# Nimble Order Description Fix

## [1.0.0] — 2026-08-29

**Изменено**

- `gamedata/configs/text/rus/st_fix_nimble_order_desc.xml` — overlay 45 ключей `zat_b51_stalker_nimble_*`.
- `gamedata/configs/text/eng/st_fix_nimble_order_desc.xml` — то же для английского.

**Причина**

Anthology намеренно подняла цены заказов Шустрого на Затоне в `dialogs_zaton.script` (`zat_b51_costs_table`), но строки в `st_dialogs_cop_zaton.xml` остались от ванильного CoP. Шустрый называет 2800 / 16 000, а списывает 20 000 / 72 000.

ZIP v1.0.0 подменял оба XML целиком (~170 КБ, 1038 строк). Изменились только 45 ключей. Полная замена конфликтует с любым модом на этот файл и теряется при обновлении сборки.

**Как исправлено**

Отдельные файлы строковой таблицы с теми же `id`. Движок грузит все XML из `configs/text/<lang>/`, повтор ключа перезаписывает значение. Имя `st_fix_nimble_order_desc.xml` идёт после `st_dialogs_cop_zaton.xml`. Скрипт, LTX и суммы оплаты не трогались.

Фактические суммы (задаток согласован / задаток после отказа / остаток при получении):

| Категория | agreed | refused | cost | итого agreed |
| --- | ---: | ---: | ---: | ---: |
| 1 пистолеты | 5000 | 1400 | 20000 | 25000 |
| 2 дробовики/ПП | 8000 | 4000 | 40000 | 48000 |
| 3 штурмовые | 12000 | 8000 | 48000 | 60000 |
| 4 снайперские | 18000 | 8000 | 72000 | 90000 |
| 5 броня | 20000 | 16000 | 80000 | 100000 |
| 6 научный | 20000 | 12000 | 80000 | 100000 |
| 7 экзоскелет | 40000 | 24000 | 160000 | 200000 |

`prepay_refused` Anthology не поднимала (как в ванили). После отказа задаток меньше согласованного, поэтому предупреждение 11131 больше не обещает «больший аванс».

**Не затронуто**

- `dialogs_zaton.script`, `plugins/nimble_orders.ltx` (тот читает только Шустрый на Кордоне)
- дерево диалогов `dialogs_cop_zaton.xml`
- состав заказов, таймеры, инфопорции
- цены и тексты Шустрого SoC (`dialogs_escape.script`)
- `all.spawn`

- Anomaly 1.5.3 / Anthology 2.1 / Modded Exes MT

- Конфликты: нет пересечения файлов с ZIP v1.0.0 (тот ставил `st_dialogs_cop_zaton.xml`). В MO2 ниже сборки. ZIP и копию тех же XML в `[DBG] Kristiano Fixes ALL IN ONE` лучше выключить, чтобы не держать полную замену зря
