# QuickQK Task Status Tool

Anomaly 1.5.3 / Anthology 2.1. Версия 1.4.1.

Аварийный инструмент: принудительно меняет статус задания, которое сейчас отслеживается в КПК.

- F7 + Q — закрыть как выполненное
- F7 + E — закрыть как проваленное

Клавиши меняются в MCM. Нужное задание должно быть отслеживаемым. Если включено подтверждение, комбинацию нужно повторить в заданное время.

Мод вызывает Task Manager (`set_task_completed` / `set_task_failed`). Condlist `on_complete` / `on_fail` при закрытии **выполнятся**. Награда, которая выдаётся только в диалоге с заказчиком, не гарантируется. Перед использованием сделайте отдельное сохранение.

## Установка (MO2)

1. Выключить предыдущие версии QuickQK, в том числе `[GFX] QuickQK Task Status Tool Anthology` из сборки.
2. Поставить этот архив отдельным модом.
3. Полностью перезапустить игру.

Имена скриптов в 1.4.1 другие (`quickqk_task_complete.script`). Если оставить старую копию включённой, обработчики задублируются.

Настройки MCM с id `quickqk` сохраняются.
