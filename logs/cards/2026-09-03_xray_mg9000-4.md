## Производительность

Источник: `* [mt-frame/profile]` (окна по 300 кадров) + `* [Lua GC/xray-atomic]`. FATAL / STACK TRACEBACK в этой сессии нет — просадка не от Lua-спама.

### База (после загрузки, 32 окна)

| Метрика | Значение |
| --- | --- |
| Средний кадр | **20.5 ms ≈ 49 FPS** |
| Средний render | 10.6 ms (в плотных сценах до ~17 ms → потолок ~45–60 FPS с GPU) |
| Окон с max ≥100 ms | **9** (микрофризы, не постоянный низкий FPS) |
| Окон со avg ≥30 ms | **2** (конец сессии, ~19–24 FPS) |
| Загрузка сейва | `engine ready` **50.4 с** (client spawn 22.8 с + precache 35.0 с) |
| До главного меню | 31.3 с |

Game/Lua в среднем лёгкие (~5 ms game worker). Основной вклад в средний FPS — **render**. Железо сильное; «вечно 20 FPS» лог не подтверждает.

### Хиты (max кадра)

| Окно | avg / max | Доминирует | Контекст рядом в логе |
| --- | --- | --- | --- |
| L2379 | 22 / **510** ms | render 454 | открытие инвентаря (`UIInventory`) |
| L2490, L2536 | 20 / 283; 18 / 209 | frame | **quicksave** ≈49060 objects |
| L2610 | 18 / 296 | frame | меню опций (`UIOptions` / ReloadUI) |
| L2748, L2768 | **51 / 537**; **41 / 827** | frame | осмотр артефактов (`loaded condition for af_*`) + `vid_monitor: live-refresh` |

Типичная жалоба «иногда дико лагает» совпадает с сейвами, инвентарём и артефактами, а не с постоянным render-bound.

### Давление Lua GC

- ~159 проходов atomic GC, avg ~12 ms, marked растёт с ~1.6M до **~15.9M** к концу короткой сессии.
- Само по себе не объясняет 500–800 ms, но усиливает фризы рядом с сейвом/UI (gc busy 21–44 в плохих окнах).

### Шум / не FPS-причина

- Missing textures ×65 (`semitone\…`, `unrealengine\explosions_new\…`) — битый/неполный графический мод.
- Missing sounds ×122 (в т.ч. `material\shells\…`, `tb_growls\…` из `tb_angry_chimera_growls`).
- `aol_sprint_cancel.script`: `invalid script_anim_part 255` — разово, не профиль.
- В cmdline есть **`-dbg`** — для повседневной игры лучше убрать.

### Что сказать другу

1. В свежем логе скриптовой аварии нет; пакет фиксов подтянут (в отличие от утренних карточек).
2. Средние ~50 FPS на RX 6900 XT / Jupiter — скорее графика/сцена + тяжёлый сейв (49k objects), не «сломался движок».
3. Ощущаемые фризы: quicksave, инвентарь, артефакты; плюс проверить зачем `-dbg` и два монитора (`vid_monitor` live-refresh в момент просадок).
4. Для сравнения: ещё одна сессия с тем же уровнем, без открытия инвентаря/сейва 2–3 минуты — прислать новый лог.
