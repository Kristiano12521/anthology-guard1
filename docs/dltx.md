# DLTX

DLTX (Differential LTX) — механизм модифицированных exe, позволяющий менять конфиги наложением, не заменяя оригинальные файлы. Anthology работает на Modded Exes, значит DLTX доступен и является способом правки конфигов по умолчанию.

## Именование

Файл-патч кладётся **в ту же папку**, что и оригинал:

```
mod_<имя_оригинала_без_расширения>_<суффикс_мода>.ltx
```

| Оригинал | Патч |
| --- | --- |
| `gamedata/configs/items/items_food.ltx` | `gamedata/configs/items/mod_items_food_anth_hunger.ltx` |
| `gamedata/configs/weapons/w_ak74.ltx` | `gamedata/configs/weapons/mod_w_ak74_myfix.ltx` |
| `gamedata/configs/system.ltx` | `gamedata/configs/mod_system_myfix.ltx` |

Суффикс — идентификатор твоего мода, он делает имя уникальным. Никаких `zzz`, `aaa` и прочих префиксов: порядок загрузки задаётся менеджером модов, а не алфавитом.

## Операторы

| Синтаксис | Действие | Проверка |
| --- | --- | --- |
| `[section]` | объявить **новую** секцию | оригинал DLTX |
| `![section]` | override существующей секции | оригинал DLTX; корпус `reference/`: 246 |
| `@[section]` | override, но секция создаётся, если её нет | **нет в оригинале DLTX**; README Modded Exes; корпус: 1 |
| `!![section]` | удалить секцию | оригинал DLTX; корпус: 0 |
| `key = value` | задать или заменить поле | оригинал DLTX |
| `!key` | удалить поле | оригинал DLTX |
| `![sec]:parent` | добавить родителя | оригинал DLTX |
| `![sec]:!parent` | убрать родителя | оригинал DLTX |
| `>key = a, b` | добавить элементы в CSV-список | **нет в оригинале DLTX**; README Modded Exes; корпус: 0 |
| `<key = a` | убрать элементы из CSV-списка | **нет в оригинале DLTX**; README Modded Exes; корпус: 0 |

Проверка. Статья [DLTX — Differential LTX Loading](https://aqxaromods.com/stalker/anomaly/2190-dltx-differential-ltx-loading-updated-25th-september-2021.html) (MerelyMezz, 25 Sep 2021) прочитана: в ней есть `![section]`, `!key`, `!![section]` (секция удаляется, только если все поля тоже удалены) и `![sec]:!parent`. Операторов `@[section]`, `>key`, `<key` в статье нет. Они описаны в [README Modded Exes](https://github.com/themrdemonized/xray-monolith) как отличия от оригинального DLTX. По корпусу `reference/`: `![` — 246, `@[` — 1, `!![` / `>` / `<` — ноль. `refindex.py` разбирает `!!` и `@` как префиксы секций; это парсер, не подтверждение употребления.

## Примеры

Изменить два поля существующей секции:

```ini
; Хлеб: меньше насыщения, больше веса
![bread]
eat_satiety = 0.15
inv_weight  = 0.4
```

Родителей повторять не нужно — база их уже знает. `![bread]:booster_multi` не пишем.

Удалить поле и добавить элемент в список (`>` — расширение Modded Exes, в оригинальной статье DLTX его нет):

```ini
![wpn_ak74]
!inv_grid_x
>ammo_class = ammo_545x39_ap
```

Создать новую секцию:

```ini
[my_new_item]:identity_immunities
inv_name = my_new_item_name
cost     = 1500
```

Снять родителя:

```ini
![vodka2]:!vodka
```

## Типовые ошибки

**Дубль базовой секции.** Если секция уже есть в базе, а патч объявляет её как `[section]` без `!`, движок падает: две базовые секции с одним именем — это `Debug.fatal`. Правка существующей секции — только `![...]` или `@[...]`.

**Патч в несуществующую секцию.** Даёт `CInifile::r_section: Can't open section 'X'` при старте либо в момент обращения. Обычно означает опечатку в имени или что мод, объявлявший секцию, не установлен. Проверка перед правкой:

```bash
python3 tools/refindex.py section bread
```

**Удаление секции без удаления полей.** `!![section]` сработает только если все её поля тоже удалены; иначе флаг игнорируется.

**Ожидание, что порядок в файле решает конфликт.** Внутри одного файла позже написанный override выигрывает, но между модами порядок определяется загрузкой в MO2.

**Копирование всей секции в патч.** Оставляй только изменяемые поля: чем меньше пересечение, тем меньше конфликтов с другими модами.

## Проверка

`tools/lint_addon.py` проверяет: имя файла соответствует шаблону `mod_*`, оригинал существует в `reference/`, патч не объявляет существующую секцию как базовую, нет `zzz`-префиксов, файл не является полной заменой оригинала.
