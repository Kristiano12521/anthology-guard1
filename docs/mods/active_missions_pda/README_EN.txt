Active Missions PDA Tab — Anthology 2.1
========================================

Port of Active Missions PDA Tab 1.2 for Anomaly 1.5.3 / Anthology 2.1.

What it does
------------
Adds a PDA "Missions" tab: active tasks grouped by type / region / faction,
expandable briefing cards, track mission.

Install
-------
1. Install the zip as its own MO2 mod.
2. Enable it AFTER Anthology core (overrides the PDA tab pager).
3. Do not merge into [DBG] Kristiano Fixes ALL IN ONE — this is standalone.

Compatibility
-------------
- iTheon PDA Taskboard: MCM option "Save PDA tab space" (off by default).
- Interactive PDA: supported.
- Saves: no custom save data.
