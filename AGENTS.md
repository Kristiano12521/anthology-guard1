# AGENTS.md

Портируемый контекст проекта: его читают Cursor и другие агентные инструменты. Cursor-специфичная логика активации (globs, always-apply) живёт в `.cursor/rules/*.mdc` — этот файл их дублирует в сжатом виде, а не заменяет.

## Что это за репозиторий

Рабочее место для разработки фиксов и аддонов к сборке **S.T.A.L.K.E.R. Anomaly 1.5.3 / Anthology 2.1** на Modded Exes MT. Сама игра здесь не лежит. Здесь лежат: правила для агента, инструменты анализа и исходники моих модов.

## Границы

| Путь | Статус |
| --- | --- |
| `reference/` | распакованные исходники сборки, **только чтение** |
| `addon/<mod_id>/` | мои моды, единственное место для правок игровых файлов |
| `build/` | результат `tools/build_addon.py`, ставится в MO2 |
| `logs/` | логи игры для разбора вылетов |
| `tools/`, `docs/`, `templates/` | обвязка проекта |

`reference/` не редактируется никогда. Правки оригинальных файлов делаются наложением: DLTX-патч для конфигов, monkey-patch для скриптов.

## Главное правило

Не выдумывать API движка. Любая незнакомая функция, callback или LTX-секция проверяется через `python3 tools/refindex.py find|section|callback <имя>` по `reference/`. Нет подтверждения — сказать об этом прямо и пометить `-- UNVERIFIED`, а не выдавать правдоподобный код за рабочий.

## Порядок работы

1. Исследование эталона через `tools/refindex.py` (не семантический поиск по `reference/`) → 2. план текстом → 3. правка → 4. проверка мест вызова → 5. `tools/lint_addon.py`.

Подробные плейбуки: `docs/plans/fix.md`, `docs/plans/addon.md`, `docs/plans/crash.md`.

## Технические константы

- Lua: LuaJIT под X-Ray. Каждый `.script` — своё окружение с `__index = _G`.
- Callback'и: `RegisterScriptCallback` в `on_game_start`, `UnregisterScriptCallback` в `on_game_end`, только именованные функции.
- `db.actor` доступен с `actor_on_first_update`.
- Конфиги: DLTX, файл `mod_<оригинал>_<суффикс>.ltx` рядом с оригиналом.
- Настройки: MCM, файл `<mod_id>_mcm.script` с `on_mcm_load()`.
- Кодировка игровых файлов: Windows-1251.
- `.ltx` не переименовывать ради load order (`zzz`/`aaa`-префиксы). У `.script` порядок задаётся именем файла; префикс — только с `-- load-order: после <что>` в первых 10 строках.
- `CHANGELOG.md` пишется после применения правки и прохождения тестов: только выполненное; невыполненное называется в ответе явно.
- Запрещено: правка `all.spawn`, слом совместимости сейвов, хардкод настроек.
